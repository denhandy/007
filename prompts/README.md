# Prompt cards

Use each card in five steps:
1. Pick the agent in the agent picker of the prompt box or type /agent.
2. Pick the mode shown on the card.
3. Replace the parts in [brackets].
4. Send the prompt once.
5. Log it in docs/prompt-log.md.

Start a new session for each story, with Environment "This computer" and Workspace "Current checkout".
Read your usage with /usage, never by counting prompts.
